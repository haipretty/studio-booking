# 工作室预约小程序

> 状态：v1.0 已开发完成 ✅ | v2.0 迭代规划中

## 项目简介

工作室会议室预约小程序，支持用户选择时间、人数，搜索可用会议室并在线支付预约费用；内置管理员后台（系统设置）。目标用户规模 100 人以内。

## 技术栈

- **前端**：微信小程序原生框架（WXML + WXSS + JS + JSON）
- **后端**：微信云开发（云函数 + 云数据库）
- **支付**：微信云开发 CloudPay（免证书、免部署回调服务器）
- **安全**：bcrypt 密码加密、管理员 token 鉴权、数据库全量走云函数

## 功能特性（v1.0）

### 用户端
- ✅ **会议室搜索**：按日期、开始时间（7:00-20:00）、时长（2 小时起）、人数筛选可用会议室
- ✅ **冲突检测**：时间段交集判定 `start1 < end2 && start2 < end1`，数据库事务防并发抢订
- ✅ **智能计价**：人数 × 单价 × 时长系数，含「大会议室惩罚」加价规则（人少订大房自动加价）
- ✅ **在线支付**：CloudPay 下单 → wx.requestPayment 拉起支付 → 回调更新订单
- ✅ **订单管理**：待支付倒计时（15 分钟）、继续支付、时限内取消并自动全额退款
- ✅ **状态机**：pending → paid → completed / cancelled，前端计时器 + 每日定时云函数双保险

### 管理端
- ✅ **管理员登录**：手机号 + 密码（bcrypt），失败 3 次锁定 5 分钟
- ✅ **系统设置**：支付时限、取消时限、营业时间、商户号配置（仅超级管理员可改商户号）
- ✅ **分级权限**：super / admin 两种角色

## 数据库设计

5 个集合：`rooms`（会议室）、`bookings`（预约订单）、`users`、`settings`（单文档配置）、`admins`

**设计亮点**：`bookings` 集合预留了多天预约字段（`startDate / endDate / days / dateList / dayPrice`），v1.0 单天模式下 `startDate = endDate`、`days = 1`，**v2.0 升级多天预约时无需迁移数据、无需改表结构**。

## 订单状态流转

```
创建订单 → pending（待支付，15分钟倒计时）
  ├─ 支付成功 → paid（锁定会议室）
  │    ├─ 预约前2小时取消 → cancelled + 全额退款
  │    └─ 预约时间已过 → completed（定时云函数兜底）
  └─ 超时未支付 → cancelled（释放会议室）
```

## 安全措施

- 数据库安全规则全部关闭读写，**所有操作经由云函数**，前端不直连数据库
- 价格由服务端计算，不接受前端传金额
- 防刷：同一用户有待支付订单时禁止创建新订单；1 分钟内最多创建 3 个订单
